# Contributing

Each project lives in Architecture-case-studies/<project-name>/ and has a README, architecture notes, implementation files and evidence appropriate to its status.

To add a project:
1. Create a descriptively named folder; include a README and working files, not an inner Git repository.
2. Link it in the portfolio and case-study indexes.
3. State what works, what was tested and what remains planned.
4. Add or update root .github/workflows/ checks; nested workflow folders are not executed by GitHub Actions.
5. Keep credentials, state, plans, deployment logs, private configuration and customer data out of Git.

Use the existing project's README checks. Run commands from that project's folder unless instructed otherwise. Deployment is manual; no workflow applies Terraform.

No open-source license has been selected. Obtain owner permission before redistribution.
