EnterpriseIQ: an authenticated knowledge assistant

Designed and implemented a serverless retrieval-augmented generation application using fictional corporate policies. The goal: turn policy questions into contextual answers with visible retrieved source references.

Architecture

Amplify serves a React application. Cognito SRP sign-in supplies an access token to an API Gateway HTTP API. A JWT authorizer protects the chat route. Python Lambda retrieves context from a Bedrock Knowledge Base backed by S3 Vectors, then calls Nova Lite through Converse. Private S3 documents are ingested using Titan Embeddings v2.

Engineering decisions

  • RAG supports policy updates through ingestion without fine-tuning.
  • VPC-free Lambda avoids NAT and private-endpoint infrastructure for a workload with no private network dependencies.
  • A separate retrieval/generation service makes offline behavior testable.
  • Stateless API requests simplify the demo; persistent history and follow-up context are future work.
  • WAF is disabled for this low-volume DEV demonstration to control cost. JWT authorization and throttling remain configured.

Results and evidence

Authenticated CLI and local-browser testing returned the fictional disaster recovery RTO of 60 minutes. Local checks passed 28 backend tests and eight mocked frontend tests, plus the production build and Terraform validation. Amplify hosting and public asset delivery were verified; the hosted interface renders. A hosted authenticated answer capture, quality evaluation, latency measurements and monthly cost evidence remain pending.

Operational troubleshooting

A live retrieval validation failure required vectorSearchConfiguration for the VECTOR Knowledge Base. A blank hosted page was traced to JavaScript and CSS returning 404. Repacking the build with Python and redeploying restored asset delivery; the precise archive-metadata incompatibility was not isolated.

Scope and limitations

This is a shared synthetic corpus, not a production multi-tenant system. Sign-in does not provide document-level authorization. Source locations are not verified sentence-level citations, and no production availability or scale claim is made. The policy's 60-minute RTO is sample content, not EnterpriseIQ's measured recovery time.
