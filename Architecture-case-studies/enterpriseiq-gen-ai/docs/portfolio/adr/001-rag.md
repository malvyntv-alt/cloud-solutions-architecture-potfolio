# ADR-001: Use retrieval-augmented generation for policy questions

- Status: accepted for the current DEV demonstration
- Recorded: November 3, 2026 (retrospective documentation of implemented decisions)
- Scope: personal project using fictional policies; not approval for enterprise production

## Business context

Answer policy questions from an updateable document corpus.

## Decision

Use a Bedrock Knowledge Base to retrieve text and Nova Lite to generate an answer through a separate Converse call.

## Alternatives considered

Existing document search; fine-tuning; a custom retrieval pipeline.

## Business benefit

Document updates can be ingested without model training. The application can expose retrieved source locations and test retrieval/generation separately.

## Consequences and risks

Relevance, freshness and unsupported output remain risks. Retrieved sources do not prove sentence-level correctness.

## Revisit trigger

Evaluation demonstrates that ordinary search meets the need better, or retrieval/generation fails the agreed quality criteria.
