FROM DEMO TO DEPLOYMENT

Built to recover.

The local demo teaches the workflow. Terraform provisions its AWS counterpart.

01 / REQUEST PATH

Authenticate. Calculate. Commit.

Route 53 resolves the endpoint. WAF protects an HTTPS ALB, Cognito authenticates users, and stateless Fargate tasks handle requests.

CognitoALBFargate
02 / ATOMIC STATE

No quote without its event.

Aurora commits a saved quote and outbox event in one transaction. A stable idempotency key protects repeated saves.

AuroraPostgreSQLOutbox
03 / ASYNC NOTIFICATION

Email stays off the critical path.

A leased publisher sends events to SQS. Lambda calls SES. Retries, partial batch failures, a DLQ, and a ledger support recovery.

SQSLambdaSES
04 / OPERATIONS

Evidence, not assumptions.

CloudWatch tracks health and backlog. CloudTrail records AWS API activity. Terraform defines infrastructure; recovery objectives need measured tests.

CloudWatchCloudTrailTerraform
DEFAULT AWS PROFILE

A smaller deployment first.

One region, one database instance, two networking AZs, one web task and one publisher. A portfolio cost compromise, not the full HA design.

EXPANSION PATH

Three AZs. Then another region.

The HA profile adds replicas and redundant compute. The DR guide covers identity, replication, notification replay, and controlled failover.
