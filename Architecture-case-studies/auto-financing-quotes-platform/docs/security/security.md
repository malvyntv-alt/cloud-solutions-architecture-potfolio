# Security boundaries



- Cognito authenticates; owner_id from verified identity authorizes access to quotes/events.
- The server verifies ALB ES256 signature, expected ALB ARN, issuer, client and signed-header expiry.
- Runtime app is private; only ALB security group reaches port 8080.
- Database is private and accepts PostgreSQL only from compute security group.
- TLS verify-full with official AWS RDS trust bundle for database connections.
- IAM roles use temporary credentials; task secrets are fetched via scoped Secrets Manager permissions.
- Aurora uses managed encrypted storage; SQS uses managed server-side encryption; secrets use Secrets Manager encryption.
- Runtime uses a non-admin database role, but three workers share that role in this portfolio version.
- CloudTrail captures AWS management API calls, not quote-row business audit or every SQS data-plane operation.
- API logs avoid customer input, email addresses and tokens. Outbox payload contains event/quote IDs, not financial inputs.
- Email uses a sign-in-protected app link rather than financial detail or a bearer link.
- CSP, JSON-only mutation endpoints and no cross-origin API allowance limit browser exposure.
- Local mode trusts a synthetic user and must never be internet-exposed. AWS mode rejects failure-control endpoints.

Not implemented in phase 1: centralized cross-account log archive, immutable cross-account backups, credential-rotation workflow, customer-managed KMS keys for each data service, identity federation configuration, full distributed traces, automated canaries, or regional DR deployment.

The managed master database secret rotates separately; the app credential is generated by Terraform and does not auto-rotate. A planned rotation must update the secret and SQL role in a coordinated migration. Running services cache the secret for up to five minutes.

Supply-chain note: Terraform providers are locked in .terraform.lock.hcl. Python requirements use constrained versions; requirements-resolved.txt records the tested environment. Production builds should use a reviewed, hash-locked dependency process.
